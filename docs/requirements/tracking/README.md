# 需求状态追踪

本目录为每条正式需求保存一份跨阶段 Markdown 状态记录。统一状态、阶段结束标志、证据要求、状态推进责任及返修复核规则由[任务执行规范§7](../../../specs/TASK_EXECUTION_SPEC.md#7-需求阶段导航与统一状态)规定。

需求定义和有效基线仍以 [`docs/requirements/`](../README.md) 中对应正式需求文档为准。本目录记录稳定需求编号、当前阶段状态、阶段交付物/版本、验收判据结果和迁移历史；链接来源，不复制需求或设计正文。记录文件按稳定编号命名，例如 `REQ-001.md`，状态变化由当前阶段负责人根据证据更新。

创建记录或补录已有需求状态时，应先核对当前有效需求基线和各阶段实际材料；不得仅凭索引摘要推断完成状态。证据不足时标明“未验证”或待处理事项，不把有文件/代码等同于验收通过。
