同域双客户端屏障运行得到一个 202 和一个 409，核对只有获准请求的用户与助手行，释放后再次提交成功。这些是同一屏障场景的阶段。前表的持有期重复提交来自先固定首请求再提交第二条的独立运行，后续广播与保留域诊断重复了该顺序提交场景。注入退出不明的独立场景使用实际 tracker 契约构造 quiescing 域，另一次 HTTP 接纳 202 后消息终结为失败，未创建新进程且旧所有者保留。构造域没有对应真实进程退出证据，保留在隔离实例的业务记录中。

同身份兼任的合并交付由[生命周期](../../collaboration_lifecycle.py#L180)写入最终文本，[调度](../../collaboration_service.py#L227)在 final_ready 发起独立调用。[预算预留](../../collaboration_actions.py#L58)与[既有同身份和异身份测试](../../test_direct_answer.py#L92)亦覆盖此区分。旧诊断的四次启动与三个接受回执对应合并路径。

隔离全批共记录 436 次受控启动，均有确认退出，运行收尾确认。原版总审计退出 1，失败条目限于五个正常协作 job 的调用数、角色和回执预期。修正夹具使 final 身份独立后，单独复跑协作 smoke 及五个 C4 请求均通过，各自执行五次及二十五次受控启动，并核对每个 job 的四个回执。全批与聚焦复跑对应不同夹具版本。

全批另覆盖同一身份跨不同对话、同一对话不同身份的受控普通消息。停止请求返回 200，运行终态为取消且确认退出；非零退出、受控超时、协议失败分别留有终态记录。同域各自的后续请求完成。默认会话配置中，Codex 与 Grok 分别观察到同域 new→resume 并核对会话标记。可选 resolver 及跨代次自然迟到回写没有本次集成验收证据。旧回调和退出不明的契约与进程测试批次复跑通过 62 项。
