## 1. 用户来源与需求基线

用户完整原文：

> 嗯，不过问题不大，然后就是我前面看到你们讨论的时候，对于防御性代码，有给出一些我们代码中的不好的例子，这个很不错，然后我还有个更不错的想法，我们把这些不好的例子，以及一些很好的例子，都作为例子，放到专门的文件中（好代码，坏代码举例），后面编写代码和检视的时候，就有现成的例子可以参考，你们觉得怎么样？合适的话，是不是可以专门搞一个文件夹，里面放这种比较好和比较差的代码例子，当然，例子放进去之后，对于好的代码，我们给出判断它好的理由，以及有没有可以更好的方式，对于坏的代码，我们要判断他坏的理由，你们看这样子做，会不会对我们以后的代码演进比较好呢 @Codex
